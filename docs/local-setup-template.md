# 本机使用说明模板（交给 agent 填写）

首次接入后，在私有配置目录保存为 `LOCAL-SETUP.md`。下面是字段模板，不是可直接运行的配置。实际路径留在本机，不上传、不同步、不提交。

- 安装版本与命令位置：待填写
- 私有配置文件：待填写
- 已选项目及允许读取、分享的文档：待填写
- 私有审核目录：待填写
- 批准历史目录：待填写
- 最终简报：待填写完整的 `ai_context.md` 路径
- 最近完成的刷新与核对时间：待填写；未完成则明确标记
- 单文件检查：项目详情和选定正文是否齐全；未完成则写原因
- 待补资料／用户尚未确认的事项：待填写

## 下次更新

对 agent 说：“按这份本地使用说明更新 ai_context”，并附上本文件路径。

agent 先核对路径与已有配置，在原有范围内扫描变化、准备审核内容；获得具体候选的批准后记录快照并重新生成。不能从本文件推断新内容已获批准，也不能因缺路径而扫描整个磁盘。

最后再次检查文件是否可单独阅读，把最终简报路径给用户。用户将新版简报上传给 ChatGPT；这份本机说明与私有配置不上传。
